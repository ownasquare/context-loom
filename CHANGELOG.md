## [0.1.0] - 2026-07-19

### Added

- A Node-free GitHub-source installation path, first-success guide, task-oriented troubleshooting,
  and concise public documentation index.
- A supported trusted in-process adapter injection seam with a runnable credential-free example.
- Structured bug and feature request forms for the intended public repository.
- A read-only Docker project mount at `/workspace`, with deterministic indexing and restart proof.
- First-run project onboarding plus in-workbench add, select, and rescan controls for multiple local
  projects.
- A result-first Prepare workflow with named conversation continuity, exact-message verification,
  cited source evidence, and recoverable omitted sources.
- Sanitized project-file previews and per-message provider usage entry for lifetime conversation
  savings.
- Installed-wheel browser coverage for onboarding, two-turn continuity, and provider usage readback.
- Local workspace registry with incremental, versioned, secret-aware indexing.
- SQLite/WAL metadata, FTS5 retrieval, deterministic similarity, and content-addressed objects.
- Fidelity-audited prompt envelopes with extractive, hybrid, aggressive, and passthrough modes.
- Optional cited Ollama compaction with deterministic fallback.
- Confidence-separated token estimates, provider usage, lifetime thread metrics, and Parquet export.
- FastAPI, Typer, MCP, generic/provider renderers, and preview-first harness integration snippets.
- Responsive React workbench with Cypress component and Playwright E2E coverage.
- Credential-free demo, benchmarks, package/container validation, and public-boundary checks.

### Changed

- Reframed integrations around three truthful delivery methods: copy and paste, MCP, and local API.
- Clarified that custom collectors and tokenizers are not public plugins and hosted release channels
  are not yet asserted.
- Added package and CLI compatibility jobs for Linux, macOS, and Windows; full browser and container
  suites remain Linux-hosted.
- Reworked the workbench into a familiar Home, Prepare, Project files, Savings, Connections, and
  Settings experience with clearer loading, error, mobile-navigation, keyboard, and modal states.
- Health and thread summaries now expose the configured message-retention mode and whether each
  prepared message already has a usage observation.
- Release checks now reject stale embedded frontend assets and verify direct SPA routes plus their
  referenced assets from built distributions.
